# Spartak FX Research

Исследовательский пакет торговой системы «Спартак / ТАП» по 11 локальным видео, сопутствующим материалам и 62 M5-инструментам.

Сначала откройте `START_HERE_RU.md`, затем `docs/project_report_ru.md`.

## Состав

- доказательная база: стенограммы, контактные листы и таймкоды;
- формализация авторских правил с отдельной маркировкой машинных гипотез;
- описание XFBAR001/XFBAR002, календарный ресемплинг и инвентарь данных;
- C++20-каркас причинной стратегии, бэктеста, временного разбиения, оптимизатора и спецификаций;
- безопасная конфигурация с `allow_audit=false` и политикой отсутствующих издержек `FAIL_CLOSED`;
- две Release-утилиты аудита в `bin/Release`.

## Сборка и тесты

Требуются CMake 3.20+ и компилятор C++20.

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Корневая конфигурация указывает на единственный проверенный вариант `build_release`. Контрольный результат: 4 из 4 тестов прошли с `/W4 /WX`.

## Честный статус

Исходные видео и BIN читаются без изменения; к брокеру проект не подключён. Top-50 и blind OOS намеренно не запускались: для всех 62 инструментов отсутствуют подтверждённые commission и swap/funding, objective ещё не зафиксирован, а постоянный криптографический lock эксперимента не реализован. Подробности и следующий безопасный этап описаны в `docs/project_report_ru.md`.

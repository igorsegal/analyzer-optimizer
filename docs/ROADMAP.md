## 2. Не сделано (по курсу)
### №2. Полная логика 4 видов РМ
Включает:
- Различение видов РМ, а не только тег.
- Правило ч.5: добор ликвидности в фазе распределения -> новый источник тренда.
- Переклассификация зон в ContextAggregator.
- Флаг `did_create_new_source` в PatternSignal.
Затрагивает: `PatternAggregator`, `PatternSignal`, `ContextAggregator`.
Приоритет: 1.
### №4. Цели (TP) от уровней
Сейчас: TP считается от фиксированного множителя риска (tp_risk_ratio = 2.0).
Нужно: TP1 = источник распределяемого импульса, TP2 = область разворота тенденции.
Затрагивает: `SignalValidator`.
Приоритет: 2. Зависит от №2.
### №6. Дивергенция
Отдельная методика (ТЗ ч.9):
- RSI-14 (для W1/MN — период 9).
- Критерии значимой дивергенции: перекрытие, зона перекупленности, ТФ H4+.
- Два сценария: замедление (~70%), разворот (~30%).
Затрагивает: новый `RSIDivergenceDetector`, `PatternType::Divergence`.
Приоритет: 3. Независимо.
### №3. Перевес / перелив
Из ч.7: фиксация баланса по таймингу формации, а не по индикатору.
Затрагивает: контекст-уровень (новый слой анализа).
Приоритет: 4. Аналитический, не критичен для кода.
### №5. Светофор
Из ч.7: стратегия от запертого объёма. По сути уже есть в зачаточном виде.
Приоритет: 5. Формализация существующего.
